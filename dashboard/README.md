# Dalph pack graph

A separate read-only interface using the same Cytoscape / Dagre renderer as
Dalph's Reducer Lab. Gas City supplies nodes, dependency edges, readiness,
execution observations, and terminality. This interface does not claim work,
start attempts, integrate commits, close beads, or persist workflow state.
Dalph runtime behavior cannot change through these GET-only views.

```sh
mise exec node@24.20.0 -- pnpm install --frozen-lockfile
mise exec node@24.20.0 -- pnpm dashboard:build
mise exec node@24.20.0 -- pnpm dashboard:serve
```

Open `http://HOST:43597/?city=dalph-expenses&scope=expenses&run=ex-aly`.
The browser calls its own origin. The server forwards API reads to the local
Gas City supervisor at `127.0.0.1:8372`; the browser never calls that loopback.
The `scope` query is the rig name. Port can be changed with `--port` when invoking
`python3 dashboard/serve.py` directly. Keep the native dashboard on port 43596
for the optional drill-through link in this trial.

The graph fills the viewport and supports pan, zoom, fit, task selection,
and an initially collapsed accessible graph summary. Parent/grouping edges
are optional. The run root appears with grouping enabled; the header otherwise
represents it. Frontier shows only supervisor `ready` steps, current work shows
`running`/`active`. Root readiness is not task readiness. An active-step border
shows the observed supervisor state, not independently proven process custody.

One Effect HTTP request runs at a time, with a 60-second timeout and a 15-second
pause after completion. A refresh failure leaves the last graph visible,
explicitly marked stale with an error. No overlapping request loop or local
workflow authority is introduced.

Acceptance scenarios and checks:

- A loaded fork/join run retains both branches and both join edges; parent
  relationships are optional. `projection.test.mjs` and the browser fixture.
- Ready and running steps receive distinct frontier/active encodings; pending
  steps are not admitted locally. Projection test and `browser.test.mjs`.
- Selecting a node shows its prerequisites and exact execution observations;
  fitting and grouping remain usable. Browser fixture.
- API failure shows an error; after a previous success the graph remains marked
  stale. Browser fixture. Request timeout is bounded; refresh uses Effect Schedule.
- A host browser uses same-origin API URLs with explicit rig scope. Live browser
  observation and recorded request URLs.

Crashes and retries of execution are outside this read-only UI boundary;
subsequent supervisor observations display their results without initiating
another attempt. The built asset is generated by `dashboard:build`.

Vendor files were copied from `prototypes/reducer-lab/src/delivery-graph-*.ts`
in `/workspace/typescript/dalph` on 2026-10-10. They retain the original visual
encoding and interaction behavior; future renderer changes need an explicit sync.

Focused checks: `pnpm dashboard:test` and `pnpm dashboard:test:browser` (with the server running and Playwright Chromium installed). The browser check uses a retained native fork/join fixture and controlled API failure, not a new task run.
