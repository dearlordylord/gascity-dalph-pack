# Native independent review and finite continuation

Gas City dispatches implementation, independent review and same-worktree fixes
through native formula expansion, check and retry controls. The pack correlates
each verdict with its task, immutable attempt, Base, reviewed commit, reviewer
session and owned worktree. Provider completion alone cannot approve a candidate.

Status: composed native review, paired controller-restart acceptance and full
runtime qualification passed. This handoff does not close the parent specification or certify
the configured interactive providers required by the later combined trial.

## Review and recovery boundaries

The first clean review ends the loop. Four completed blocking reviews exhaust
automatic convergence; transport and malformed verdicts use separately finite
native infrastructure retries. Human continuation opens another finite,
deduplicated batch against the same retained attempt and fourth-round findings.
Native outer delivery scopes skip qualification and delivery after failed review.

Implementation owns the worktree. Review and fix nodes borrow it through native
workspace configuration; preparation requires their exact configured base.
Frozen formula steps carry workspace and product identity before compilation,
so lazy retries preserve those identities. Mirrored native control metadata does
not make a control node an executable implementation, fix or delivery node.

Gas City owns session retirement. Completed actors request their own native
drain acknowledgement; the pack observes exact closed or positively reassigned
sessions before accepting their retained work. Open unfinished, foreign, manual
and ambiguously reassigned sessions retain custody and resources. Known closed
sessions omitted by native listing are observed by exact public tracker ID.
Reassignment never authorizes closing the new owner.
